How the platform works

An edge architecture built for the plant floor.

Each layer does its work as close to the asset as possible. Raw signals stay on site; what moves is the information people need to act.

  1. 01 · Sense

    Industrial sensors

    Vibration, temperature, motor current and environmental conditions, placed where they inform the components that matter.

  2. 02 · Process at source

    Feature extraction

    High-frequency signals are processed at or near the sensor, so only meaningful features need to travel across the site.

  3. 03 · Connect

    Site-appropriate link

    Connectivity matched to the environment: existing networks where available, long-range, low-power wireless where cabling is impractical.

  4. 04 · Edge node

    Store, analyse, alert

    An on-site edge node holds the data, runs the analytics and serves local dashboards and alerts, and is designed to keep working without an internet connection.

  5. 05 · Optional

    Customer-approved cloud

    Cloud sync, remote support and off-site analysis only when you choose to enable them.

How our analytics are designed

In development and validation

From raw signal to useful insight

High-rate vibration is reduced to compact features at the sensor. The edge node compares them with each machine’s learned normal behaviour, so meaningful change can be seen and raw data can stay on site.

  1. 01Raw signal at the sensor
  2. 02Spectrum, processed at source
  3. 03Compact features sent to the edge
  4. 04Compared with learned normal
  1. 01

    Learns each machine’s normal

    Models are calibrated on each machine’s own healthy operation, not generic assumptions.

  2. 02

    Reads the whole picture

    Signals are interpreted together and in operating context, so routine changes aren’t mistaken for faults.

  3. 03

    Understands the machine’s structure

    Alerts relate to specific components, not just individual sensors.

  4. 04

    Shows its reasoning

    Established engineering checks sit alongside the learned model, so alerts can be explained.

  5. 05

    Learns from outcomes

    What maintenance teams find is fed back, so performance is measured honestly and improves over time.
